PRÁCTICA N2 GIT, GITHUB Y HTML

  1. ¿Qué es Git y cuál es su función principal dentro de un proyecto de desarrollo?

    Git es un sistema de control de versiones que permite registrar y administrar los cambios
    realizados en los archivos de un proyecto y su funcion principal es mantener un historial de cambios
    permitiendo volver a versiones anteriores y trabajar de manera organizada

  2. ¿Cuál es la diferencia entre Git y GitHub y qué función cumple cada uno?

    Git es una herramienta de control de versiones que funciona principalmente de manera local en nuestro ordenador
    mientras que GitHub es una plataforma en linea que permite almacenar repositorios Git, compartir proyectos y trabajar de manera colaborativa

  3. ¿Qué pasos se deben seguir en Git para guardar los cambios realizados en un proyecto y crear un commit?

    • Primero se revisan los cambios con git status
    • Despues se agregan los archivos con git add .
    • Finalmente se crea un commit -m "un mensaje"

  4. ¿Qué comandos se utilizan para conectar un repositorio local con un repositorio de GitHub y posteriormente
    subir los cambios? Explique brevemente la función de cada uno.

    • Para connectar un repositorio local con GitHub se usa git remote add origin URL_DEL_REPOSITORIO
    • Para verificar la conexion es con git remote -v
    • Para subir los cambios es con git push origin main

  5. ¿Qué es una rama (branch) en Git y en qué situaciones puede ser útil trabajar con una rama diferente a main?

    Una rama es una linea independiente de trabajo dentro de un repositorio y es util para realizar cambios, desarrolar nuevas funciones
    o haceer pruebas sin modificar directamente la rama principal main

  6. Explique el proceso para crear una nueva rama, realizar cambios en ella y posteriormente subir esa rama a un repositorio de GitHub.

    • Primero se cra la rama con: git branch nombre de la rama ejemplo git branch auxilituras
    • Despues se cambia a la rama git checkout auxiliaturas
    • Se realizan los cambios y se agregan los archivps con git add .
    • se crea un commit -m "un mensaje"
    • Finalmente se sube a la rama a GitHub con git push -u origin auxiliaturas

  7. ¿Qué es un conflicto en Git y qué pasos se deben seguir para resolverlo antes de combinar los cambios de una rama con main?

    Un conflicto ocurre cuando Git encuentra cambios diferentes en las mismas lineas de un archivo y no puede decidir automaticamente cual debe conservar

    Para resolverlos se deben segir estos pasos:

    • Identificar el archivo que presenta el conflicto
    • Abrir el archivo y revisar las partes marcadas por Git
    • Decidir que cambios se deben conservar
    • Eliminar las marcas del conflicto
    • Guardar el archivo
    • Agregar el archivo con git add .
    • crear un commit -m "un mensaje"
    • Finalmente continuar con las combinacion de las ramas
