Practica N°3

Preguntas teoricas:

  1. Existen dos formas principales de conectar un archivo HTML con JavaScript. Explique cuáles son estas 2 formas y proporcione un ejemplo básico de cada una.

    Existen dos formas principales de conectar un archivo HTML con JavaScript. La primera es usando JavaScript interno,
    que consiste en escribir el código JavaScript directamente dentro del archivo HTML utilizando la etiqueta por ejemplo:

    a) JavaScript interno: el código se escribe dentro del mismo archivo HTML, usando la etiqueta <script>.

    <script> console.log("Hola desde JavaScript interno"); </script;>

    b) JavaScript externo: el código se escribe en un archivo aparte (por ejemplo script.js) y se conecta con el atributo src de la etiqueta <script>.

    <script src="script.js"></script>

    Y dentro del archivo script.js:

    console.log("Hola desde JavaScript externo");

  2. Explique paso a paso cómo visualizar los resultados de JavaScript utilizando la consola del navegador.

    1. Escribir en el código de JavaScript la instrucción console.log() con lo que queremos mostrar. Por ejemplo: console.log("Hola");
    2. Abrir el archivo index.html en el navegador
    3. Abrir las herramientas de desarrollador presionando la tecla F12
    4. Hacer clic en la pestaña Consola
    5. Ahí aparecen los mensajes que pusimos en console.log().

  3. Explique qué son las variables en JavaScript y cuál es la diferencia entre var, let y const. Incluya un ejemplo
    sencillo de cada una e indique cuál de estas formas ya no se recomienda utilizar actualmente y por qué.

    Las variables en JavaScript son espacios donde se almacenan datos o valores. Se pueden declarar con var, let y const.
    por ejemplo: var nombre = "Juan";, let edad = 15; y const pi = 3.14;. La diferencia es que var es una forma antigua,
    let permite cambiar el valor y const no permite reasignarlo. Actualmente no se recomienda usar var porque puede causar confusiones por su alcance. Se recomienda usar let y const.
